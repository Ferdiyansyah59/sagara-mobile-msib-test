# Aplikasi Weather Menggunakan React Native

Aplikasi Weather ini dibuat menggunakan React Native. Ikuti langkah-langkah berikut untuk menjalankan aplikasi ini:

## Cara Penggunaan

1. **Clone Repository Ini:**

2. **Jalankan Command "npm install":**
   Di terminal pada direktori project, jalankan perintah berikut untuk menginstall semua dependensi

3. **Jalankan Aplikasi:**
   Gunakan salah satu perintah berikut untuk menjalankan aplikasi:
   **npx expo start**
   atau
   **npm run start**

4. **Scan QR Code atau Jalankan dengan Emulator:**

- Scan QR Code yang muncul di terminal atau browser menggunakan aplikasi Expo Go (tersedia di Android dan iOS).
- Jika kamu ingin menjalankan aplikasi di emulator, klik "A" pada terminal. Pastikan emulator sudah terbuka sebelum menjalankan perintah ini.

5. **Aplikasi Weather Siap Digunakan:**
   Setelah langkah-langkah di atas, aplikasi Weather siap digunakan pada perangkat atau emulator kamu.
